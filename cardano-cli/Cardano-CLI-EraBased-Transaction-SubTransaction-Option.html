Cardano.CLI.EraBased.Transaction.SubTransaction.Option

Description

Parsers for Dijkstra sub-transactions: the sub-transaction command group and the --signed-sub-tx-file option with which a top-level transaction embeds signed sub-transactions.

Synopsis

pSubTransactionCmds :: IsEra era => Maybe (Parser SubTransactionCmds) Source #

The sub-transaction command group. Sub-transactions exist from Dijkstra onwards, so the group is absent in Conway.

pSubTransactionFiles :: IsEra era => Parser [SignedSubTxFile 'In] Source #

Signed sub-transactions to embed in a top-level transaction. Only Dijkstra has sub-transactions, so the option does not exist in Conway.
